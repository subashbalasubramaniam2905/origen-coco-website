# Origen Coco website templates

Twelve homepage directions for Origen Coco (coconut and coir products, Pollachi, Tamil Nadu), built as static HTML.
Open `index.html` to browse them. Each template is a self-contained page in this folder; photos and logos are in `assets/`.

Hosted with GitHub Pages from the `main` branch.

Before launch: connect the enquiry form to a form service, add the factory's exact map location and the social media account links.
